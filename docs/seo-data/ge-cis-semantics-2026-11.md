**Дата замера:** 9 ноября 2026. **Кто:** SEO-редактор (`praxen-seo-editor`), скиллы `seo`, `yandex-wordstat`. **Для чего:** календарь `docs/blog-ge/CALENDAR-2026-11.md` (10.11–09.12.2026), правило 9 CLAUDE.md (.ge — по статье в день с 9 ноября).

## Метод

- **Источник частотностей — Яндекс Вордстат** (API Yandex Cloud Search, `topRequests`, 100 фраз на запрос, все устройства). Цифра — показы в месяц за последний период, который отдаёт API. Для Казахстана цифры совпали с замером 24.10.2026 (`docs/seo-data/wordstat-kz-2026-10-24/`), значит, API отдаёт тот же закрытый период. Частотность в Вордстате «широкая»: в «нейросети для бизнеса» уже входят «лучшие нейросети для бизнеса», поэтому вложенные фразы в таблицах не складываем.
- **Регионы:** Грузия 169, Казахстан 159, Армения 168, Азербайджан 167, Узбекистан 171. ID проверены запросами по столицам: «тбилиси» в регионе 169 — 215 876 показов, «ереван» в 168 — 345 583, «баку» в 167 — 134 139, «ташкент» в 171 — 133 826, «алматы» в 159 — 1 573 044. Россия 225 — только для поиска формулировок (столбец `RU_ref_225`), целью не считается.
- **Фразы:** 120 исходных фраз в 20 группах (чат-боты, WhatsApp, Telegram, Instagram, запись, ИИ-ассистенты и агенты, ChatGPT, внедрение, автоматизация, продажи, CRM, обучение, голос, база знаний, документы, отрасли, гео-модификаторы, дополнительные). Фразы 0–43 сняты по каждой из 5 стран отдельно; для фраз 44–115 Грузия и Казахстан — отдельно, Армения, Азербайджан и Узбекистан — одним запросом (столбец `AM+AZ+UZ_AMAZUZ`), потому что по ним почти везде ноль; фразы 116–119 — только Грузия и Казахстан. ## Что важно знать о цифрах

1. **Яндекс в Грузии, Армении, Азербайджане и Узбекистане почти не используют.** Сумма по всем фразам «top» за месяц: Казахстан 62 823, Грузия 2 410, Азербайджан 1 407, Армения 765, Узбекистан 280 (по фразам 0–43; по 44–115 Армения + Азербайджан + Узбекистан вместе — 529). Коммерческие фразы вне Казахстана — 0–15 показов. Реальный спрос там идёт через Google (в Грузии по Google сильнее английские запросы: «AI chatbot» 1 300, «AI agent» 260, `search-volume-georgia-2026-10.csv`). Поэтому цифры .ge-календаря маленькие, а Казахстан даёт основную часть.
2. **Гео-модификаторы не дали ничего.** «чат бот (грузия|тбилиси|батуми)», «(ии|нейросеть|искусственный интеллект) (грузия|тбилиси|батуми)», «(автоматизация|crm|внедрение) (грузия|тбилиси|батуми)» — 0 во всех пяти странах. Слова «Грузия», «Тбилиси», «Батуми» в title новых статей спрос не добавляют; оставляем их там, где статья про задачу в Грузии.
3. **Грузинский язык Вордстат не покрывает.** Спрос на ka — только через Google и Search Console.
