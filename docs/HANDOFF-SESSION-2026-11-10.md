## Инструменты Meta в новой сессии
- Это три ручных workflow в GitHub (ref `main`). Ключи лежат в секретах GitHub (`META_TOKEN`, `THREADS_TOKEN`, `TELEGRAM_*`), переносить их в новую сессию не нужно.
- `social-report.yml` — статистика Facebook, Instagram, Threads, Telegram и рекламных кабинетов, отчёт выходит зашифрованным. `meta-ads.yml` — реклама, запускать только по «да» владельца; режим `scopes` проверяет права ключа. `threads-replies.yml` — `check`, поиск и ответы в чужих ветках.
- Репозиторий публичный, поэтому отчёт шифруется открытым ключом из входа `pubkey` (base64 PEM). Закрытый ключ живёт только в scratchpad сессии и пропадает вместе с ней.
- Как прочитать отчёт в новой сессии: создать пару ключей заново (`openssl genpkey -algorithm RSA -pkeyopt rsa_keygen_bits:3072`), запустить workflow с новым `pubkey`, скачать журнал, расшифровать строки `KEY:` и `DATA:` (`openssl pkeyutl -decrypt … -pkeyopt rsa_padding_mode:oaep`, затем `openssl enc -d -aes-256-cbc -pbkdf2`). Закрытый ключ и отчёт в репозиторий не класть.
- 11.11.2026 проверено: всё работает. Охват страницы Facebook починен: Meta сняла метрику `page_impressions_unique`, теперь берём `page_media_view` и `page_total_media_view_unique`, каждую отдельным запросом.
- Не хватает: у `THREADS_TOKEN` нет права `threads_keyword_search`, поэтому поиск чужих постов не работает. Нужно от владельца: выдать права `threads_keyword_search` и `threads_manage_replies` в приложении Praxen Threads и заменить секрет `THREADS_TOKEN`.
