# Команда агентов Praxen AI

Создана 10 ноября 2026 по решению владельца. Файлы агентов — `.claude/agents/*.md`. Главное правило: автор и проверяющий — разные агенты, своё никто не принимает.

## Разработка нового продукта

| Агент | Что делает | Кто проверяет его работу |
|---|---|---|
| `business-analyst` | Идея владельца → описание функции (экраны, правила, «Как проверить») в `docs/specs/` | Владелец даёт «да» на описание |
| `solution-architect` | Технологии, данные, интеграции, решения в `docs/adr/`, план по шагам | `security-reviewer`, `code-reviewer` |
| `ux-ui-designer` | Сценарии, макеты, дизайн-система, проверка готовых экранов на 1440 и 390 | `qa-engineer` |
| `frontend-developer` | Экраны и интерфейс | `code-reviewer`, `qa-engineer`, `ux-ui-designer` |
| `backend-developer` | Сервер, база, вход, оплаты, интеграции | `code-reviewer`, `security-reviewer`, `qa-engineer` |
| `code-reviewer` | Проверка каждой доработки до выкладки | — (не пишет код сам) |
| `security-reviewer` | Вход, доступы, ключи, персональные данные, оплаты | — |
| `qa-engineer` | Сценарии проверки, автотесты, вердикт «можно выпускать» | — |
| `devops-engineer` | Автовыкладка, окружения, резервные копии, оповещения, расходы | `code-reviewer` |
| `product-analyst` | Метрики, события, воронки, недельный отчёт | — |
| `tech-writer` | Справка для пользователей, инструкции, документация | `praxen-editor-in-chief` |
| `praxen-legal` | Черновики оферты, политики данных, договоров (Грузия, Британия) | Юрист и владелец |

Порядок: `business-analyst` → «да» владельца → `solution-architect` → `ux-ui-designer` → разработчики (сначала тест, потом код) → `code-reviewer` → `security-reviewer` (вход, оплаты, данные) → `qa-engineer` → `devops-engineer` выкладывает.

## Маркетинг и продажи Praxen

| Агент | Что делает | Кто проверяет |
|---|---|---|
| `praxen-marketing-strategist` | Кому продаём, позиционирование, предложение, план каналов | Владелец утверждает план |
| `praxen-seo-editor` | Темы блога по спросу, брифы, проверка дублей | `praxen-editor-in-chief` |
| `praxen-copywriter` | Статьи и тексты сайтов | `praxen-editor-in-chief`, `source-verifier` |
| `praxen-editor-in-chief` | Проверка всех текстов перед публикацией | — |
| `source-verifier` | Проверка фактов, цифр и источников | — |
| `praxen-smm` | Контент-план и посты соцсетей | `praxen-editor-in-chief`, `praxen-creative-designer` |
| `praxen-creative-designer` | Картинки постов и рекламы, проверка до публикации | — |
| `praxen-performance-marketer` | Реклама Meta и Яндекс Директ, бюджеты, отчёты | Владелец даёт «да» на запуск и бюджет |
| `praxen-sales-lead-gen` | Списки компаний, цепочки писем, отклики Upwork, CRM | Владелец отправляет сам |
| `praxen-presales` | Коммерческие предложения и сметы по входящим запросам | Владелец |
| `praxen-account-manager` | Ведение клиента после продажи, итоги пилота, продление | Владелец |
| `praxen-reporting-analyst` | Еженедельные и месячные отчёты по сайтам, соцсетям, рекламе, заявкам | — |
| `praxen-georgian-editor` | Первая вычитка грузинских текстов | Команда владельца |

Скиллы каждого агента перечислены в его файле. Агенты продукта копируются в репозиторий нового продукта, когда он будет создан.
