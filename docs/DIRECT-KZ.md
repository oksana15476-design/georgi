# Яндекс Директ: Казахстан (praxenai.ge, русский)

**Дата:** 24 октября 2026. **Статус:** на согласование владельцу. Бюджет — в рублях, суммы ниже предварительные, владелец меняет по своему решению.

**Спрос.** По Казахстану коммерческих запросов о внедрении ИИ мало (Google Ads, `docs/seo-data/volumes-ru-KZ-UZ-AM-GE-2026-10-07.csv`): «ии агенты» ~390 в месяц, «ии ассистент» ~210, «автоматизация бизнеса» ~90, остальное по 10–50. Поэтому для воркшопа основной объём даст Рекламная сеть Яндекса (РСЯ), поиск — дополнение.

**Время воркшопа для Казахстана:** 12 ноября, **20:00 по Астане** (вся страна с марта 2024 года в UTC+5; в Тбилиси 19:00).

**Как считаем результат.** Яндекс Метрика на сайте включается только после согласия на cookie, поэтому цели в Директе почти не наберутся и обучение по конверсиям не заработает. Стратегия — «Максимум кликов» с недельным бюджетом. Результат считаем по меткам UTM: они попадают в сделку amoCRM (поля UTM source / campaign) и видны в отчёте «Проверка воронки» на странице владельца.
