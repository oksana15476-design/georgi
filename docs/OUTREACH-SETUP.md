# Инфраструктура аутрича: Грузия, ЕС, UK

**Дата:** 2026-10-06. Спрос по рынкам — `docs/EU-DEMAND.md`, запуск в Грузии — `docs/LAUNCH-GEORGIA.md`, карточка компании — `docs/LISTINGS.md`.

## Главное правило

Холодные письма **не** отправляются с `praxenai.ge`. Основной домен держит сайт, заявки и переписку с клиентами; если его репутация упадёт, в спам уйдут и ответы клиентам. Для аутрича — отдельные домены, похожие на бренд, с редиректом на сайт.

## 1. Домены и ящики

| Шаг | Что | Где |
|---|---|---|
| 1.1 | 2–3 домена для рассылок: `praxenai.com`, `praxen-ai.com`, `getpraxen.com` (или `.eu` / `.co.uk` под рынок) | Cloudflare Registrar или INWX |
| 1.2 | Редирект каждого домена на `https://praxenai.ge` (Cloudflare → Rules → Redirect) | Cloudflare |
| 1.3 | Почтовые ящики на этих доменах: 2–3 на домен, на имя человека (`evgeny@`, `e.budnikov@`) | Google Workspace (~$7/ящик) или Microsoft 365 |
| 1.4 | DNS: SPF, DKIM, DMARC (`p=none` на старте, через месяц `quarantine`) | Cloudflare DNS |
| 1.5 | Прогрев 2–3 недели, затем не больше 20–30 писем в день с одного ящика | встроенный прогрев в Instantly / Smartlead |

Ящики на Cloudflare Email Routing для этого не подходят: они только принимают почту.

## 2. Инструменты

| Задача | Варианты |
|---|---|
| Рассылка, прогрев, ротация ящиков | Instantly или Smartlead (email); Lemlist (email + LinkedIn) |
| Базы контактов | Apollo.io (ЕС, UK), LinkedIn Sales Navigator; для Грузии — Google Карты (отели, клиники, застройщики), сайты и Facebook компаний |
| Проверка email перед отправкой | MillionVerifier, NeverBounce |
| LinkedIn | ваш профиль (основатель, фото, заголовок «AI implementation for business»), 15–25 приглашений в день вручную или через Sales Navigator |
| Запись на звонок | Cal.com → ссылка в письмах и на сайте (`NEXT_PUBLIC_BOOKING_URL`) |
| CRM | HubSpot Free или amoCRM (сайт уже умеет отправлять заявки в amoCRM) |

## 3. Правила по рынкам (проверить с юристом перед стартом)

| Рынок | Холодный email B2B | Что обязательно |
|---|---|---|
| Грузия | Допустим; лучше работают WhatsApp, LinkedIn, личные встречи | Отписка, понятно кто пишет |
| UK | Допустим на корпоративные адреса (PECR), на личные адреса ИП — нет | Отписка, название и адрес компании, основание — legitimate interest |
| ЕС в целом | По GDPR — legitimate interest, письмо релевантно должности | Отписка, источник данных по запросу, адрес компании |
| Германия, Австрия | Холодный email без согласия запрещён (UWG) | Только LinkedIn, партнёры, входящий трафик |

Для ЕС/UK в каждом письме нужен реальный юридический адрес компании → сначала оформить ИП/компанию в Грузии.

## 4. Что поменять на сайте перед ЕС/UK

- Политика конфиденциальности (EN): раздел про обработку данных для B2B-аутрича (источник, legitimate interest, отказ), обработчики — Cloudflare, Google, Meta, Яндекс; передача данных из UK/ЕС.
- Цены для ЕС/UK в EUR/GBP — отдельным предложением, не перевод из лари (`docs/EU-DEMAND.md`).
- Пруфы: 2–3 кейса из Грузии до массового выхода в ЕС/UK. Без них ответов будет в разы меньше.
- Ссылка на запись (Cal.com) и LinkedIn основателя на сайте.

## 5. Порядок

1. Неделя 1: домены, ящики, DNS, старт прогрева; LinkedIn основателя; Cal.com.
2. Неделя 1–3: базы по ICP, проверка адресов, тексты последовательностей (4–5 касаний).
3. Неделя 3: старт в Грузии (тест сообщений, 1–2 пилота со скидкой за кейс).
4. После 2–3 кейсов: UK и Нидерланды на английском, Германия — только LinkedIn.
