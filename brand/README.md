# Логотип Praxen AI

Знак и надпись повторяют логотип сайта (`components/praxen/ui.tsx`). Текст в SVG переведён в кривые: шрифт устанавливать не нужно.

Цвета: тёмно-синий `#121a2b`, синий `#315bf5`, серый «ai» `#5d6779`. На тёмном фоне: белый, `#7b95ff`, `#a9b3c6`. Шрифт надписи — Manrope Bold / Regular.

| Файл | Куда |
|---|---|
| `praxen-avatar-dark-1080.png` | Аватар: Facebook, Instagram, LinkedIn, YouTube, Telegram, Google Business Profile, Clutch и каталоги. Знак в центре, круглая обрезка его не режет |
| `praxen-avatar-light-1080.png` | Тот же аватар на белом, если нужен светлый |
| `praxen-logo.svg` / `praxen-logo.png` | Горизонтальный логотип на светлом фоне (прозрачный фон): документы, КП, презентации, сайты-каталоги |
| `praxen-logo-white.svg` / `praxen-logo-white.png` | Горизонтальный логотип для тёмного фона (прозрачный фон) |
| `praxen-logo-on-white.png` / `praxen-logo-on-navy.png` | Логотип с полями на белом и тёмно-синем фоне — когда сервис просит картинку, а не прозрачный файл |
| `praxen-mark.svg` / `praxen-mark-white.svg` / `praxen-mark-512.png` | Только знак |
| `praxen-app-icon.svg` / `praxen-app-icon-512.png` | Иконка со скруглёнными углами (как фавикон сайта) |
