# Praxen AI: praxenai.ge и praxenai.com

Перед любой работой прочитай `docs/HANDOFF.md` целиком: там устройство проекта, правила владельца, что сделано и что осталось. Каждый пуш в `main` сразу выкатывается в Cloudflare на оба сайта.

## Главное (правила владельца)

1. **Ничего не ломать.** Не менять логику без нужды. Каждый изменённый блок открыть в браузере на 1440 и 390 до пуша.
2. **Не сбивать SEO.** Адреса страниц не менять (если нельзя иначе — 308-редирект и замена ссылок). Не убирать страницы из карты сайта, не ставить noindex, не трогать robots.txt, canonical и hreflang без решения владельца. Title, description и H1 страниц с показами менять только по данным Search Console / Вебмастера. Одна страница — один запрос.
3. **.ge и .com — разные компании для своих рынков.** В разметке друг на друга не ссылаются; рынки, цены, профили и темы статей не смешиваются. На .com Грузию в продающих текстах не упоминаем.
4. Ничего не выдумывать (отзывы, рейтинги, клиенты, цифры без источника). Тексты без «ИИ-шности».
5. Не коммитить ключи и токены. Не отправлять тестовые заявки без согласия владельца.
6. Отвечать владельцу по-русски, коротко, без жаргона.
7. **Блог — только с согласования владельца** (решение 9 октября). Статьи в блоги пишем только с согласования владельца: сначала присылаем ему темы и план, пишем и публикуем после его «да». Правки уже опубликованных статей — тоже через него.
8. **Темы и статьи блога уникальны — на .com и на .ge** (решение 9 октября). Статья может раскрывать коммерческую страницу (услугу, отрасль, отдел) и ссылается на неё. Внутри блога повторов и дублей нет: один запрос — одна статья, один тезис — одна статья-владелец, остальные ссылаются; у каждой статьи свои примеры и расчёты, общие оговорки (оплата токенов, данные на аккаунтах клиента, бесплатный аудит) не повторяются в каждой статье. Между сайтами темы разные. Статьи ведёт редакция: SEO-редактор → копирайтер → главред, порядок и чек-лист — `docs/BLOG-EDITORIAL.md`. Разбор текущих статей — `docs/BLOG-AUDIT-2026-10.md`.

## Проверки

- До пуша: `npx tsc --noEmit -p .`, `npx eslint components lib app`, для статей — `npx tsx scripts/qa/blog-check.ts`; сборка и скриншоты (`scripts/qa/`, см. HANDOFF).
- После выкладки: `node scripts/qa/live-check.mjs` — все адреса из карт сайтов отвечают 200, canonical на себя, без noindex, уникальные title, robots.txt и карты сайтов в порядке.
- Статьи блогов — по скиллу `.claude/skills/praxen-blog/SKILL.md`.
