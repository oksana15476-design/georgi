# social-content

Пачка постов — это один JSON-файл в `content/social/` (например, `2026-11.json`). Скрипт `scripts/social/render.mjs` делает из него картинки и готовые подписи.

## Перед тем как писать

1. Прочитать `docs/CONTENT-STRATEGY.md`: каналы, рубрики и их доли, правила честности, календарь.
2. Просмотреть прошлые пачки в `content/social/*.json`, чтобы не повторять темы и заходы.
3. Сверить факты:
   - цены — `lib/pricing.ts`;
   - формулировки услуг — `lib/site-copy.ts`, `lib/content.ts`;
   - есть ли подтверждённые кейсы — `casesVerified` в `lib/proof.ts`.
4. Если пользователь дал цифры за прошлый месяц (Метрика по `utm_source=facebook`, Insights), опираться на рубрики и форматы, которые дали записи на аудит.

## Правила текста

- Пока `casesVerified=false`, отраслевые сценарии помечаются `"example": true` (на карточке появится «Пример сценария»), а в подписи пишется «Это пример сценария». Никаких «наш клиент» и выдуманных отзывов.
- Расчёты подписываются «Пример расчёта».
- Обещания — только из сайта: аудит бесплатный, 30 минут; пилот 2–4 недели; решение на аккаунтах клиента; токены и серверы клиент оплачивает напрямую.
- Первая строка подписи — крючок: ситуация или вопрос клиента. Конец подписи — один призыв и `{link}`, затем 3–5 хештегов.
- Заголовок карточки — до ~8 слов. Пункт списка — одна строка мысли. Слово в `*звёздочках*` выделяется синим.
- Все три языка пишутся сразу. Грузинский — естественный, не дословный перевод; терминология как на сайте (`AI`, `AI ასისტენტი`, `უფასო აუდიტი`). В итоге напомнить пользователю, что грузинский должен вычитать носитель.

## Формат JSON

```json
{"campaign":"organic_2026-11","langs":["ka","ru","en"],"posts":[
 {"id":"01-topic","date":"2026-11-09","pillar":"usecase|tips|myths|process|money|offer|about",
  "link":"https://praxenai.ge/ru/industries/hotels",
  "text":{"ka":"…{link}…","ru":"…{link}…","en":"…{link}…"},
  "slides":[{"layout":"cover", "...": "..."}]}]}
```

- `link` — адрес на русской версии; для каждого языка путь меняется на `/ka`, `/en`, к адресу добавляются UTM-метки. Якоря на главной: `#quiz`, `#calculator`, `#contact`. Отрасли: `/industries/<slug>`, отделы: `/departments/<slug>` (slug — в `lib/content.ts`).
- Текстовые поля — `{"ka":…,"ru":…,"en":…}` или одна строка для всех языков.

Макеты слайдов (у каждого есть необязательный `kicker` и флаг `example`):

| layout | Поля | Фон |
|---|---|---|
| `cover` | `title`, `sub` | тёмный |
| `list` | `title`, `items[]` (до 5) | светлый |
| `dialog` | `title`, `messages[]` с `from: client|bot`, `time`, `text` (до 4 сообщений) | светлый |
| `compare` | `title`, `before[]`, `after[]` (по 3), необязательно `beforeLabel` / `afterLabel` | светлый |
| `number` | `value`, `label`, `note` | тёмный |
| `cta` | `title`, `sub`, `button` | тёмный |

Карусель — 3–5 слайдов: обложка → суть → `cta`. Длинный текст скрипт уменьшает сам, но лучше сократить.

## Сборка и проверка

```sh
node scripts/social/render.mjs content/social/2026-11.json             # всё
node scripts/social/render.mjs content/social/2026-11.json 03-topic ka  # один пост, один язык
UTM_SOURCE=instagram node scripts/social/render.mjs content/social/2026-11.json  # подписи для другого канала
```

Результат: `content/social/out/<пачка>/<пост>/<язык>-<n>.jpg` и `captions.md` с подписями по языкам и готовой подписью для Facebook (ka + ru).

Перед коммитом собрать картинки в общий лист и посмотреть глазами: ничего не обрезано, грузинские строки не рвутся некрасиво. Затем добавить пачку в календарь в `docs/CONTENT-STRATEGY.md`.
